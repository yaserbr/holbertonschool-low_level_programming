# Hash Tables

This directory contains tasks for learning hash tables in C.

## Learning Objectives

- Understand what a hash function is
- Create and use hash tables
- Handle keys and indexes
- Use the djb2 hash algorithm
- Work with structs and dynamic memory allocation

## Files

| File | Description |
| --- | --- |
| `hash_tables.h` | Header file containing structures and function prototypes |
| `0-hash_table_create.c` | Creates a hash table |
| `1-djb2.c` | Implements the djb2 hash function |
| `2-key_index.c` | Gets the index of a key |

## Compilation

```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o hash_tables
```
